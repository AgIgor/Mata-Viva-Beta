# Mata Viva · Beta

Jogo de sobrevivência no cerrado e na mata brasileira, feito para rodar direto no navegador (celular e computador).

**Jogar:** https://agigor.github.io/Mata-Viva-Beta/

- Mundo gerado por semente, com biomas, fauna, clima e estações
- Coleta, criação, construção, roça, criação de animais e pesca
- Eras da pedra, cobre, ferro e vapor, com força mecânica e automação
- Multiplayer: *Jogar junto* › *Criar sala* e passe o código para quem vai entrar

Versão de testes. Todo o jogo está em `index.html`.
